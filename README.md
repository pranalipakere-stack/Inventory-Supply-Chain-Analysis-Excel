# Inventory & Supply Chain Analysis Using Excel

## Project Overview

This project analyzes inventory and supply chain data using Microsoft Excel. The goal is to understand inventory levels, sales performance, supplier lead times, stockouts, and lost sales units through data analysis and an interactive dashboard.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas
- Data visualization and dashboard design

## Dataset Information

The dataset contains 3,600 records and 23 columns related to inventory items, suppliers, warehouses, stock quantities, costs, sales, and stockout information.

**Dataset Source:** [Inventory Data Studio – Items and Stock](https://inventoryoptimization.pro/inventory-data-studio/)

## Key Performance Indicators (KPIs)

- Total Inventory Value
- Total Stock Quantity
- Total Revenue
- Stockout Records
- Lost Sales Units
- Average Lead Time

## Dashboard Analysis

The dashboard presents the following analyses:

1. Stockout Status Distribution
2. Inventory Value by Category
3. Revenue by Category
4. Average Lead Time by Supplier
5. Stock Value by Warehouse
6. Lost Sales Units by Category
7. Stock Quantity by Category and Warehouse

## Key Insights

- Total inventory value is approximately 38.11 million.
- Total stock quantity is 1,832,833 units.
- Total revenue is approximately 23.77 million.
- The dataset contains 114 stockout records.
- Total lost sales due to stockouts are 15,934 units.
- Fasteners have the highest lost sales units among the listed categories, at 4,939 units.

## Project Objective

The objective of this project is to practice Excel-based data analysis and dashboard creation while developing skills relevant to entry-level Data Analyst roles.

## Files Included

- `Inventory_Supply_Chain_Analysis(Recovered).xlsx` — Excel workbook containing the inventory analysis and dashboard.
- `README.md` — Project documentation.

## Conclusion

This project demonstrates how Microsoft Excel can be used to summarize inventory data, analyze supply chain performance, identify stockout-related losses, and present findings through a dashboard.
